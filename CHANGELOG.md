# Changelog

All notable changes are documented here.

## 0.4.2 - 2026-08-30

- Added an asynchronous, opt-out update checker for compatible stable GitHub releases.
- Added a once-per-session local Minecraft message with installed/latest versions and a clickable
  GitHub Release link.
- Added a 24-hour local update cache, strict metadata validation, bounded HTTPS response handling, short
  timeouts, and silent offline failure.
- Added public repository metadata, clean-build workflows, release checksums, documentation, and MIT
  licensing.
- Preserved the existing collector, catchbook tooltip, Fish Stats HUD, privacy, and exact-server gate.

## 0.4.1 - 2026-08-30

- Added schema-2 collector rows with real collector/Minecraft versions and explicit field-quality state.
- Preserved raw environmental display separately from semantic weather/time fields.
- Improved Fish Stats HUD spacing and persistent status labels.

## 0.4.0 - 2026-08-30

- Added compact HUD alerts for backpack, bait, quests, contests, events, records, discoveries, and
  correlated rewards.
- Added silent startup baselines and bounded persisted notification state.

## 0.3.2 - 2026-08-30

- Integrated personal catchbook statistics into the existing FishOn tooltip frame.
- Added compact and Shift-expanded views with safe screen placement.
